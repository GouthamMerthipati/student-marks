# Student Marks Analyzer

## Description

Student Marks Analyzer is a simple Python project that calculates
the average marks of a student and displays the student's marks
and average score.
## Features

- Stores student marks
- Calculates average marks
- Displays student information
- Displays the average score
## Requirements

- Python 3.x
## Installation

Clone the repository:

```bash
git clone https://github.com/GouthamMerthipati/student-marks.git
```

Move into the project directory:

```bash
cd student-marks
```
```bash
...
```
## Usage

Run the following command:

```bash
python student_marks.py
```

The program will display the student's name, marks, and average score.
